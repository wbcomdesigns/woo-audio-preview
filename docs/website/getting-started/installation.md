# Installation

## Install the plugin

1. Upload the `woo-audio-preview` folder to `/wp-content/plugins/`, or install
   it from Dashboard > Plugins > Add New.
2. Activate the plugin from the Plugins screen.
3. Make sure WooCommerce is installed and active first. Without it, the plugin
   deactivates itself and shows a notice.

After activation the plugin redirects you to its settings screen.

## Find the settings screen

The settings screen lives under the shared Wbcom hub:

**WB Plugins > Audio Preview**

It has three tabs: Welcome (a quick-start guide), General (PRO) (a free vs Pro
comparison), and FAQ. The free plugin has no functional options to configure on
this screen; all preview configuration happens per product.

## Add your first preview

1. Edit any WooCommerce product.
2. Scroll to the **Audio Preview Items** meta box below the product data.
3. For each track, enter a name (for example "Intro Sample") and either click
   **Media Library** to upload or select a file, or paste a URL.
4. Leave a row empty to skip it. You do not have to use all three rows.
5. Click **Update**. The player appears on the product page immediately.

See Usage > Adding audio previews for the full walkthrough.
