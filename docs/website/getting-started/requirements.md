# Requirements

Confirm the following before installing.

| Requirement | Version |
|---|---|
| WordPress | 5.0 or higher |
| PHP | 7.4 or higher |
| WooCommerce | Required, must be installed and active |

## WooCommerce is mandatory

The plugin declares WooCommerce as a required plugin. If WooCommerce is not
active, the plugin deactivates itself on activation and shows an admin notice
asking you to install and activate WooCommerce. It cannot run without it.

## Browser and device notes

- The player is responsive and works on modern desktop and mobile browsers,
  including iOS and Android.
- OGG audio does not play on iOS (iPhone and iPad). If your audience is mainly
  on iOS, use MP3.
- Right-to-left (RTL) stylesheets are included for RTL languages.
