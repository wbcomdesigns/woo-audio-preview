# Settings screen

The plugin adds a screen under the shared Wbcom hub at **WB Plugins > Audio
Preview**. It uses the shared Wbcom settings shell, so it looks like every other
Wbcom plugin's admin.

The free plugin has no functional options to set here. All preview
configuration is done per product (see Adding audio previews). The screen is
informational, plus the place the Pro add-on adds its own tabs.

## Tabs

| Tab | Purpose |
|---|---|
| Welcome | Quick-start guide, key features, and best-practice tips. |
| General (PRO) | A free vs Pro feature comparison table and an upgrade call to action. |
| FAQ | Common questions answered in an accordion. |

## Free vs Pro (as shown on the General tab)

| Feature | Free | Pro |
|---|---|---|
| Audio previews per product | 3 (fixed) | Unlimited |
| Add / remove audio files dynamically | No | Yes |
| External URLs and CDNs | Yes | Yes |
| Multi-vendor support (Dokan, WCFM, and so on) | No | Yes |
| Custom player themes | No | Yes |
| Preview duration control | No | Yes |
| Watermark / voice-over protection | No | Yes |
| Bulk import | No | Yes |
| Support | Community | Priority email |

The Pro add-on is a separate purchase. See the General (PRO) tab for the current
price and upgrade link.
